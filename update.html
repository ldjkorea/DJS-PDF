1.2.1 업데이트 APK 다운로드

Android 8.0 이상 · 1.15 MB · versionCode 4

업데이트 방법

  1. 위 버튼으로 APK를 받거나 DJS PDF 앱에서 업데이트 확인 → 지금 업데이트를 누릅니다.
  2. 앱에서 설치 권한 필요 안내가 나오면 설정으로 이동을 눌러 Android 설정의 이 출처의 앱 허용을 켭니다. DJS PDF로 돌아온 뒤 업데이트 확인 → 지금 업데이트를 한 번 더 눌러 다운로드를 시작합니다.
  3. 받은 APK를 열고 Android 설치 화면에서 업데이트를 선택합니다.
  4. DJS PDF를 열어 최근 문서와 책갈피를 이어서 사용합니다.

1.2.0에서 설치 출처를 처음 허용하면 다운로드가 자동으로 재개되지 않습니다. 설정에서 돌아온 뒤 위의 업데이트 버튼을 다시 눌러 주세요. 이미 해당 출처가 허용돼 있으면 이 설정 단계는 건너뜁니다.

이번에 개선한 점

  • 같은 이름의 다른 PDF를 구분하고 문서와 책갈피를 함께 안전하게 저장합니다.
  • 암호 재시도·취소와 손상 파일 처리를 개선해 읽던 문서를 유지합니다.
  • 검색·페이지 맞춤·연속 스크롤·모바일 화면과 현재 문서 공유를 개선했습니다.
  • PDF 실행 경계와 업데이트 파일의 무결성 확인을 강화했습니다.
