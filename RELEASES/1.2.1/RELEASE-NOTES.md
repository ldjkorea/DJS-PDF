# DJS PDF 1.2.1

PDF 저장·열기·공유·업데이트의 안정성을 개선했습니다. 기존 앱을 삭제하지 않고 아래 APK로 **업데이트 설치**하세요.

## 기존 문서와 책갈피를 유지하는 업데이트

1. DJS PDF의 **업데이트 확인**을 누르거나 아래 APK를 다운로드합니다.
2. Android 설치 화면에서 기존 DJS PDF에 **업데이트**를 선택합니다.
3. 앱을 열어 최근 문서와 책갈피를 이어서 사용합니다.

**기존 앱을 삭제하거나 Android 설정의 데이터/저장공간 삭제를 실행하지 마세요.** 서명이 다르다는 설치 오류가 나오면 기존 앱을 삭제하지 말고 설치를 중단하세요. 앱에 남아 있는 문서와 책갈피를 보존하기 위해 패키지·서명·파일 origin·DB 이름과 스키마를 유지했습니다. 같은 이름·크기의 다른 PDF는 내용 해시로 구분하며, 기존 형식의 문서를 처음 열 때 읽기 상태와 책갈피를 이어받고 옛 저장 원본도 유지합니다.

## 주요 수정

- 문서 내용 기반 식별 및 파일·메타의 원자 저장으로 같은 이름의 문서와 책갈피 충돌 방지
- 암호 입력 재시도·취소, 손상 PDF 열기 실패 시 기존 문서 유지
- 검색 결과, 페이지 맞춤, 연속 스크롤, 모바일 버튼 배치 및 렌더링 작업 경합 개선
- 현재 문서의 정확한 바이트를 공유하고, 읽기 전용 URI와 해시 검증 적용
- PDF.js의 알려진 동적 코드 생성 취약 경로 제거, CSP 및 네이티브 파일 접근 범위 제한
- APK 다운로드의 HTTPS·크기·해시·패키지·버전·서명 검증 강화

## 검증 범위

- Node 회귀시험 14개, Java 파일 안전 검사 14개 통과
- 전용 에뮬레이터에서 1.2.0→1.2.1 업데이트 및 합성 기존 문서·책갈피 이전 검사 통과
- 실제 SM-S942N에서 1.2.0→1.2.1 업데이트 후 기존 문서 2개·책갈피 1개·앱 설정의 원본 해시와 메타 유지 확인
- 실기기 합성 PDF 열기·책갈피 재열기·Android 볼륨 키 이벤트·공유창 호출·별도 앱 UID 수신 파일 무결성 검사 통과

볼륨키 검사는 실기기에 Android 입력 이벤트를 주입한 자동 검사입니다. Samsung 공유창의 시험 수신 앱 선택은 완료되지 않아 같은 준비 파일 URI를 로컬 시험 앱에 명시적으로 전달해 수신 바이트와 읽기 전용 권한을 확인했습니다. 일반 수신 앱에서의 실제 발송, 장시간·대용량 읽기, 모든 기종을 검증한 결과는 아닙니다. 과거 버전에서 이미 덮어쓴 원본 파일은 이번 업데이트로 복구할 수 없습니다.
